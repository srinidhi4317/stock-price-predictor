# stock-price-predictor
This project predicts the next day’s stock closing price using Linear Regression trained on historical market data.

🔍 Features
Downloads real stock data using Yahoo Finance API (yfinance)

Uses Linear Regression for prediction

Visualizes Actual vs Predicted prices

Predicts next day’s closing price

📁 Files Included
Stock_Price_Predictor.ipynb — main notebook

README.md — project documentation

📊 Model Used
Linear Regression

Input feature:

Previous day’s closing price

Output:

Next day’s predicted closing price

📈 Example Output
Code
Predicted next day price: 190.53
